# algorithms-ctd

Algorithm and data structure practice for the Code the Dream apprenticeship.

## Structure

- `data-structures/` - reusable reference implementations (linked list, BST, ...)
- `exercises/` - solutions grouped by topic (`arrays/`, `strings/`, `linked-list/`, `trees/`, `graphs/`, `matrix/`, `intervals/`, `patterns/`)
- `notes/` - explanatory notebooks and write-ups

## Conventions

- Directories use lowercase-with-hyphens, files use snake_case.
- Each exercise file is self-contained and runnable: description,
  INPUT/OUTPUT, BRAINSTORM, implementation, then test cases at the bottom.
- When an exercise has multiple solutions, keep all variants in the same file
  (see `exercises/linked-list/reorder_list.js`).
- Run a JS solution with `node exercises/<topic>/<file>.js`; Python with
  `python3 exercises/<topic>/<file>.py`.
